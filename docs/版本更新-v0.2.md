# v0.2：从介绍网站到找工位工作台

2026-10-15。沿用流动工位 / FlowSeat 品牌，替换发现页布局与交互，保留上一版费用、菜单、空位和社区体验能力。

## 可以实际操作

- 首屏直接进入上海工位探索，列表与地图共享筛选条件和选中状态。
- 点列表或标记打开地图预览，镜头将选中点移到预览上方；列表悬停临时强调地图点。
- 按工作意图、类型、费用、片区组合筛选，搜索即时生效；空结果可以清除条件重试。
- “帮我选一处 / 换一处”在当前筛选结果中依次选择，不伪装 AI 推荐，也不捏造实时有座。
- 最多三处地点并排对比预算、类型、插座、椅子、网络与工作区域；少于两处时不能开始对比。
- 地图可缩放、复位；手机支持地图 / 列表切换和地点预览。
- 地点页通过办公条件、菜单、到访须知、社区体验面板切换，减少平铺长页面；返回探索保留正常导航过程中的筛选与选中状态。
- 收藏保持本机存储；新增按钮按压、收藏反馈、地图聚焦、预览切换、对比托盘和手机底部抽屉动效。
- Web 补齐 uni-app 自定义按钮的 Enter / Space 激活、详情页左右方向键切换；弹层支持 Escape 与焦点循环。系统减少动态效果时收敛空间运动。

## 当前边界

这仍是可交互的产品验证版：四个地点、菜单和价格均为虚构；地图是示意，不提供真实定位、路况或导航。空位、体验、纠错与收藏只在本机保存；账号、支付、多人社区判定、商家菜单服务尚未接入。没有宣称完成真实闭店投票或实时余座查询。
