# 部署指南

适用范围：早期原生微信小程序准备稿。当前首发改为跨端 Web，请先看 [跨端技术方案](跨端技术方案.md)，此处微信身份与集合不能直接当作 Web 当前实现。

当前是准备状态，不表示已部署。真实账号的认证、备案、付费产品与云资源开通按实际账号完成；本轮没有创建收费资源。

## 当前账号准备

用户目前只有域名，没有小程序、云环境和支付账户。现有域名暂不需要接入微信云函数调用链路，不先购买服务器或配置域名 HTTPS。

先在微信公众平台注册小程序，按实际可注册的主体选择并核验服务类目；注册、实名认证、扫码确认与备案资料由用户本人处理。完成后仅提供 AppID 和账号状态，不提供 AppSecret。个人主体的展示、反馈、开放共创与付费能力分别核验；若平台不允许计划中的功能，再调整主体或功能，不先作支持承诺。

下载并安装微信开发者工具，导入现有项目。先开一个开发环境并确认收费条件，在开发／体验版中完成真机验证；进入公开运营前再落实生产环境隔离与发布资料。开通云资源和产生费用不是本轮已执行的操作。

首轮不申请支付商户号，不接入付费。未来地图买断先核对实际虚拟支付准入，再决定需要的账户与配置。

## 1. 预览骨架

安装微信开发者工具，导入项目根目录。默认 AppID 为 `touristappid`，配置为 `preview`；仅预览页面，地图为空。没有真实云环境时，登录与审核明确报未配置，不返回假成功。

在终端运行：

```sh
npm run check
npm test
```

这些检查不替代微信编译、地图渲染和真机登录。

## 2. 绑定开发账号与环境

在微信公众平台取得 AppID 并添加开发成员。开通微信云开发的开发环境，记录环境 ID。已有环境先确认所属小程序和费用，不复用其他产品的生产库。

执行以下命令，替换示例值，不输入密钥：

```sh
npm run configure -- --appid wx0123456789abcdef --env your-dev-env-id
```

脚本更新 `project.config.json` 和 `miniprogram/config.js`，切换为 cloud 模式。服务端身份配置与客户端 AppID 必须一致。

## 3. 创建数据与规则

在开发环境创建 `users`、`places`、`review_tasks`。对每个集合单独应用 `infrastructure/database.rules.json`：客户端 read/write 均为 false。模板文件在磁盘上不会自动部署。

按控制台实际查询要求建立索引：

- places：city、status、_id 的组合查询及 _id 升序分页。
- review_tasks：status、createdAt 升序。

不要为了查询成功将权限改为所有人可读写。云函数使用服务端访问，权限控制另在业务代码完成。

V0.1 可以保持空地点集合。不导入虚构上海咖啡店或测试到访作为真实数据。

## 4. 部署云函数

在开发者工具选择对应云环境，将 `cloudfunctions/api` 上传并部署，使用云端安装依赖。依赖已锁定 `wx-server-sdk` 4.0.2；云端运行时选择平台当前支持的 Node.js 版本，并进行实际调用验证。

设置云函数环境变量：

- `MINIPROGRAM_APPID`：真实 AppID，必须配置。
- `REVIEWER_OPENIDS`：首次先留空；任何账号默认没有审核权限。

设置合理的超时、预算告警与日志保留，不将密钥、完整身份和用户内容打印进日志。函数环境变量变更后按控制台要求发布生效。

## 5. 设置你的审核权限

1. 你的微信账号进入开发／体验版，点击登录。
2. 在“我的”点击“复制我的账号标识”。只返回当前微信调用者自己的 OpenID。
3. 在云函数环境变量 `REVIEWER_OPENIDS` 填入这个标识，重新生效。
4. 回到小程序刷新登录与权限，看到快速审核入口。
5. 使用另一微信账号调用同一审核接口，必须返回无权限。仅检查按钮隐藏不够。

不采用“第一个登录的人自动成为管理员”，避免其他体验用户抢到权限。后续迁移环境时重新核对 AppID 与身份映射。

## 6. 真机联调

使用实际 AppID 与云环境，在 Android 和 iPhone 分别检查登录、空地图、列表／地图切换、错误重试、账号权限与旧隐藏链接。V0.1 未实现定位、投稿、购买和审核动作，不把未实现项当测试通过。

检查首次与重复登录、云数据库缺失、函数配置错误等情况：错误不能变成空地图或伪登录成功。新增 users 文档不能覆盖已有昵称。

## 7. 后续发布生产

创建隔离的生产环境并配置预算。依次部署数据库规则／索引、兼容云函数、前端真实配置。审核白名单只授予实际需要的账号。

完成账号资料、实际服务类目、备案、隐私保护指引、联系与账号删除入口；付费版另完成平台支付开通、商品、各端价格、推送、权益、退款和真单验证。

开发者工具上传版本 → 公众平台设置体验版 → 真机验收 → 提交审核 → 审核通过后发布。当前没有完成这些步骤；具体平台等待时间不做保证。

原生地图与位置服务按实际使用核验商业范围；自建外部 HTTPS 服务以后才配置请求域名等相应能力。当前云函数调用路径不需要先租独立服务器，但也不免除平台备案与发布资料。

生产回滚：保留上一前端版本及云函数构建，接口向后兼容，数据库变更保持可恢复。代码版本回滚不撤销真实支付记录或审计历史。
