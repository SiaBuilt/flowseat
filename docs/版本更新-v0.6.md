# v0.6 · 补充一项

2026-10-21。保留私有内测，不新增公开地点。对应开发计划 D3 的用户微任务部分。

- 地点页可「补充一项」：插座数量、座椅舒适度、Wi-Fi、电脑办公许可、桌面条件、开放时间、进入方式；每次只填一项，需写现场说明，可附来源链接。
- 补充先进入体验审核队列，通过后只更新这一项，并记录到访日期、说明、来源与审核编号（`observations`）；不自动认证整个地点。
- 同一用户同一地点同一项只能有一条待审核补充；审核时若该项已被他人更新、地点已隐藏或依据超过 30 天，拒绝通过。
- 确认「不允许电脑办公」或「桌面放不下」的补充一经通过，地点自动隐藏；核心条件（电脑许可、桌面、费用、开放时间）补充后重算上架门槛，不满足则转回候选。
- 无来源链接的核心字段补充不沿用旧证据，也不宣称已核实。
- 「我的贡献」展示补充的前后值与审核状态。

46 项根目录测试与 26 项服务端测试通过，客户端类型检查通过。商家确认链接、微信身份、电话 Agent 仍未接入。
