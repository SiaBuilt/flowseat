# v0.5 · 逐项来源与停车候选

2026-10-20。本版保留私有内测，不新增公开地点，不代替商家核实。

## 用户可见变化

- 黑白界面重新调整字级、留白、圆角、搜索与筛选层次；保留克制的费用语义色。
- 卡片渐入、悬停、选中、收藏和弹层反馈；系统偏好减少动态效果时关闭动画。
- 详情新增「信息来源」和「附近停车」。虚构地点不查询真实停车；展示来源类型、核对日期与过期提示。
- 投稿支持逐项填写电脑许可、桌面条件、费用、开放时间的依据；支持“0 个”插座。
- 审核显示缺项，服务端阻止没有近期逐项依据、费用、开放时间或进入方式的上架／恢复。

## 已实现的技术范围

证据首版存于地点结构化内容，编辑仍重新审核；审核操作沿用原审计。尚未完成研究规划中的独立观察历史表、冲突决议、多源自动抽取、商家确认链接和电话 Agent，不能称为完整 D1—D4。

停车接口仅查询可见地点已提供的上海 GCJ-02 坐标，取 500 米内最多 5 条候选；相同供应商 ID 去重，短期进程缓存。直线距离、内部标注与未知费用／余位明确区分。未完成停车设施实体级合并、车行入口核实和费率模型。地图不返回可停证明。

腾讯 Web 地图适配及服务端代理包含在本版。虚构目录保留布局示意；真实地图仅展示真实地点坐标。无 Key／网络错误时提供列表与外部导航。微信登录仍未接入。

38 项接口和领域测试通过；客户端类型检查、Web／小程序与服务端构建通过。小程序仅编译验证，未在开发者工具及真机测试。浏览器检查桌面／手机、筛选、选点、详情标签和减少动效偏好。Grok 参考站浏览器遇到访问验证，本版按用户指定的黑白方向设计，不声称精确复刻原站动效。
