# v0.5.1 · 到访核对与来源保留

2026-10-20。保留私有内测，不新增公开地点。

- 已登录用户可在「信息来源」提交到访核对，每次最多 2 项，每人每项每天一次。弹窗展示当前字段值，信息不符引导纠错。
- 到访核对复用体验审核队列，审核前仅本人和审核员可见；通过后单独展示到访日期与现场说明，不覆盖官方依据、不刷新官方依据日期、不修改地点规则。
- 费用或时间未知时不能确认。审核时地点已隐藏、字段已变动或记录超过 30 天，均拒绝通过。
- 原始来源保留；核对内容存入体验记录，审核操作有审计。当前只展示各字段最近一次通过的到访核对，尚无完整多来源冲突决议界面。
- 地点链接支持 `tab=sources` 等标签参数。微信身份、商家确认链接、电话 Agent 仍未接入。

40 项接口与领域测试通过，覆盖未登录拒绝、每人每日去重、审核前不公开、来源保留、未知字段拒绝、条件变动与隐藏状态拒绝。Web、小程序与服务端需按本次发布构建；小程序未做真机测试。

线上部署状态以 Sites 返回为准；自动浏览器访问线上域名遇到 Cloudflare 403，不能据此宣称腾讯地图线上渲染已验收。Key 已验证与页面渲染验证是不同状态。
