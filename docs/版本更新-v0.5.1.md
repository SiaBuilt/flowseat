# v0.5.1 · 到访核对

2026-10-20。本版只让已收录地点保持可核对，不新增公开地点，也不替代商家确认。

## 用户可见变化

- 地点「信息来源」新增「我刚到访，核对信息」。登录用户每次最多勾选两项：电脑办公许可、桌面条件、费用规则、开放时间；填写现场情况后，这几项的核对日期更新为当天。
- 核对只更新来源类型（到访体验）、日期与说明，不修改字段值；同一项每天只记录一次。发现内容不一致，仍走「地点纠错」。
- 费用未知、开放时间待确认的字段不能核对，服务端会提示先补充实际信息。
- 地点链接支持标签页参数，例如 `?tab=sources`，分享时可以直达信息来源。

## 边界

- 到访核对是用户自述，公开页只展示「到访体验 · 核对于日期」和现场说明，不展示账号信息；处理记录留存于服务端审计。
- 尚未实现独立观察历史表与冲突决议：同一字段多次核对只保留最新日期，旧记录在审计日志中，不能按字段回溯成时间线。
- D3 的商家确认链接、D4 电话试验仍未开始。真实地点继续先核实后发布。

## 验证

39 项接口与领域测试通过，覆盖到访核对、每日一次、未知字段拒绝与未登录拒绝；客户端类型检查、Web 与服务端构建通过。桌面截图核对了「信息来源」面板与核对弹窗。小程序仅共用源码，未在开发者工具与真机验证。
