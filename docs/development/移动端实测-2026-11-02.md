# 移动端实测 2026-11-02

环境：本地最新功能版 `http://127.0.0.1:8860`，真实 Chrome，CUA viewport 390×844 与 320×844；腾讯 SDK 真实加载。未将仿真视为手机真机验收。

## 已取得的实际证据

- 旧 Chrome 窗口截图白屏，但 DevTools 中首页文字、354×43.5 标题尺寸与 display:block 正常；新建独立窗口恢复页面绘制与浏览器 API。没有据此修改业务代码。
- 390 宽真实地图显示 42 地点聚类；逐次点击聚类可缩放到城区并分离地点。实际点击 WeWork 威海路点后选中态及预览卡更新为该地点。
- 320 宽账号匿名页能展示登录引导；推荐入口打开投稿表单，展开“补充设施、菜单和到访规则”成功。
- 320 宽投稿 document.scrollWidth=320，输入字体16px，首批输入边界31..289，无横向溢出。

## 实测发现与修复复测

- SDK 地图覆盖层 z-index:1000 越出地图层级，在底部地点卡上绘制标记，遮住标题与正文；同一层拦截“查看列表”按钮点击。只读 elementFromPoint 确认按钮中心命中 SDK 覆盖层；按钮本身 z-index:12，320宽时矩形 x83.94/y780/w152.13/h44。
- SDK 默认缩放控件和产品自有缩放按钮同时出现，互相重叠。
- 全栈已修复地图 stacking isolation，并移除 SDK 默认缩放控件。最新本地构建复测：320宽“查看列表”切换成功、列表点选北外滩图书馆后回地图并更新预览；elementFromPoint 命中切换按钮自身；地图标记不再遮挡预览卡，缩放只剩一组，腾讯比例尺和版权保留。详情按钮成功进入地点页。
- 320宽列表 scrollWidth=320，没有横向页面溢出。
- 重合坐标列表最终逐项选择尚未完成真实点击验收，逻辑测试不能替代此项。
