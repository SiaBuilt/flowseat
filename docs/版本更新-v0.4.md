# v0.4：真实数据试用准备

2026-10-19。沿用 FlowSeat / 流动工位、黑白界面与费用状态的克制语义色。

## 本次完成

- 新增一次性数据库迁移，六条上海公开资料进入待审核队列，署名“FlowSeat 资料整理”，来源日期保留。重复执行、此前已经手动导入或已有审核结论时均不覆盖或重复建点。候选不是已公开的地点；两家历史咖啡馆线索条件未知，仍不能直接通过。
- 投稿与编辑可选填高德 GCJ-02 经纬度，草稿和审核队列保留数据。服务端拒绝缺项、字符串坐标、其他坐标系及上海范围外的点；精度统一六位小数。坐标与其他信息一起审核，不自动从示意图推算经纬度。
- 有坐标时，地点导航使用高德单点标注；没有坐标时继续按名称和地址搜索，并提示核对同名门店。这里是外部地图导航，内嵌地图仍为明确标注的布局示意。
- 首页直接读取最新一小时内的社区余座，列表与详情同步；过期及未来时间反馈不作为实时余座。坐满不影响地点营业状态。
- 刷新页面和切换账号时重新加载真实收藏，清除旧账号留下的客户端展示状态；本地存储仅用于演示地点。
- 搜索支持详细地址、多个词和全角拉丁字符。对比明确区分“无 Wi-Fi”和“Wi-Fi 待确认”。商家菜单不再错误标注为演示价格。

## 验证

29 项自动测试通过，覆盖权限、闭店恢复、坐标、真实余座列表、迁移去重与已有审核结果保留。客户端和服务端 TypeScript、Web 和微信小程序构建通过；小程序没有真机验收，App 尚未打包。

本地隔离库浏览器验证：账号审核入口、六条线索导入、两家历史咖啡馆发布按钮禁用、编辑回填、坐标输入以及 390px 手机布局。手机文档宽度与视口同为 390px，无横向溢出。截图：`previews/flowseat-v4-mobile.jpg`。本地旧测试地点和本机登录信息不随源码或迁移上传。
