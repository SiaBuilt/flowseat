## 提交与发布

在项目根目录执行 Git 命令，提交到 GitHub 主仓库。进入 `site-preview` 执行 Git 命令时操作的是平台部署仓库，两者提交独立。修改后可在根目录使用 `git add -u` 更新已跟踪文件；该目录新增文件需要注意嵌套仓库的忽略行为，确认新文件确实进入主仓库。

GitHub 推送不会自动更新线上网站，当前仍通过 Sites 工作流单独发布。已有线上版本与本地开发版本可能不同。

忽略真实环境配置、密钥、数据库、运行缓存、依赖目录和发布压缩包。密钥只在对应部署环境设置，不写入代码或文档。
