# Web 产品截图

`web-explore.jpg`、`web-detail.jpg`、`web-compare.jpg`、`web-contribute.jpg` 由当前功能版 Web 的本机演示环境实际操作截取。浏览器桌面视口为 1440 × 1050。探索与对比保留完整桌面视口（含地图版权或整个弹窗），各为 1440 × 1050；探索列表为产品自身的可滚动面板，并非展示全部 8 张卡片。详情完整页面为 1440 × 1280，已填写虚构示例且未提交的投稿完整页面为 1440 × 2590，均包含底部内容。旧的非 `web-` 图片保留作历史素材。

## 演示数据范围

8 处地点均为虚构，名称带「演示」，地址标明「请勿前往」。费用、时间、Wi-Fi、插座、座椅、工作分区、停留与进入规则为产品展示数据，不是店铺事实或实访结论。地图底图与缩放、聚类、选择、列表及对比交互来自当前 Web 实现；演示坐标不用于出行导航。未连接生产数据库，也不模拟真实登录。

演示脚本使用独立内存数据库，关闭真实地点自动导入，启动时重新生成数据。为了让现有地图显示演示点，fixture 使用普通地点的渲染路径；HTTP 服务仅在输出的 JavaScript 中把来源提示替换为「虚构地点 · 产品演示」、明确虚构数据与地图不可导航，将「社区收录」改为「演示收录」，并标明插画虚构。这些文字替换不写回生产源码或构建产物。因此截图展示的是当前 Web 的演示环境，而非原样生产页面或审核完成证明。

## 本机复现

在项目根目录执行（Node.js 22.13+）：

```sh
npm run build:web
npm run sync:web
node scripts/readme-demo.mjs
```

浏览器打开 `http://127.0.0.1:8863/`。详情可用 `/#/pages/index/index?id=showcase-1`，投稿可用 `/#/pages/contribute/index`。探索页勾选两处地点的「对比」即可查看对比表。结束后按 Ctrl+C，内存数据随进程销毁。

地图从被 Git 忽略的 `site-preview/.dev.vars` 读取 `TENCENT_MAP_KEY`；缺少该本机配置时地图服务关闭，脚本不输出密钥。服务仅监听 `127.0.0.1`，不可发布到公网。投稿页匿名状态用于展示表单；此环境不提供真实登录。
