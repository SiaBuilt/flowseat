# v0.7 · 商家确认链接

2026-10-21。保留私有内测，不新增公开地点，不联系真实商家。对应开发计划 D3 的商家确认部分。

- 审核员在「我的 · 审核」为地点生成商家确认链接：复制即可发给场地方，14 天有效、只能提交一次；为同一地点重新生成会作废旧链接。服务端只存链接的哈希值。
- 商家免登录打开链接，看到地点名称、地址和目前记录，逐项选择「与现状一致」或「更正 / 补充」，填写称呼或职务即可提交；不收集手机号。可确认电脑办公许可、桌面条件、费用规则、开放时间、进入方式、Wi-Fi、插座数量。
- 提交先进入审核队列，显示前后值与联系人；不出现在社区体验列表。通过后更新对应字段，核心字段依据标为「商家自述」，地点页「信息来源」单独展示商家确认块，注明不等于独立实测。
- 审核时若该项已被他人更新、地点已隐藏或提交超过 30 天，拒绝通过；商家确认不允许电脑办公或桌面不足会隐藏地点；已发布地点缺项会转回候选。
- 新增数据表 `merchant_links`（迁移 `0002_merchant_links.sql`），线上发布前需按顺序应用。

49 项根目录测试与 29 项服务端测试通过，客户端类型检查通过；本地浏览器已走通商家打开链接、补充一项、提交后链接失效。商家身份目前靠审核员电话或官方渠道回访，没有自动核验；微信身份、电话 Agent 仍未接入。
