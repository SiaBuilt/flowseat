# 基础接入核对

适用范围：早期原生微信小程序准备稿。当前首发改为跨端 Web，请先看 [跨端技术方案](跨端技术方案.md)，此处微信身份与集合不能直接当作 Web 当前实现。

核对日期：2026-10-14。官方文档与当前账号实际权限均需核对；本文件不表示账号已开通或平台已批准。

## 技术选择

首版采用原生微信小程序（JavaScript、WXML、WXSS）＋微信云开发云函数＋文档数据库。地图首先使用原生 map 组件；POI 搜索等扩展服务单独接入。不建设独立管理后台，不先采购服务器或开发多端框架。

云开发仍然是服务端：负责身份、权限、数据、审核和后续支付处理。它减少服务器维护，不意味着所有业务逻辑都写在客户端。费用按账户当前套餐、调用和存储核算，不假设永久免费。

## 登录与身份

| 问题 | 首版结论 |
|---|---|
| 是否需要账号密码 | 不需要，使用微信身份 |
| 是否需要手机号 | 不需要，首版不请求 |
| 浏览是否强制登录 | 不强制创建产品账号；平台调用上下文仍可能包含身份 |
| 什么时候创建用户资料 | 用户主动点击登录时，由云函数创建 |
| 云开发如何识别用户 | 服务端读取 `cloud.getWXContext()` 的 OPENID 和 APPID |
| 是否自己维护登录 token | 当前微信云调用路径不另建 token；若未来改自建服务，再使用 wx.login／code2Session 与服务端会话 |
| 昵称头像 | 初始使用产品内默认昵称，后续用户自主填写与选头像，不声称自动读取微信资料 |
| 审核员如何设置 | 用户登录后复制自己的账号标识，在云函数环境变量中加入指定 OpenID；服务端校验 |
| 是否需要 UnionID | 单一小程序阶段不依赖；未来跨应用再评估 |

当前骨架不涉及手机号、头像上传、用户实时位置。用户署名、图片、定位能力在后续版本按实际数据处理补充隐私声明与平台配置。

## 账号主体与付费

当前已确认：用户只有自己的域名，尚未注册小程序，没有 AppID、微信支付或云开发环境。优先轻量上线验证，域名暂不接入；先完成账号注册与开发／体验版，付费后置。主体选择先核对展示、结构化反馈与未来共创／虚拟支付的允许范围，不假定个人主体一定支持全部功能。注册、实名认证及备案资料需由用户本人完成。

地图及评价买断是数字信息／功能解锁场景，优先核验微信小程序虚拟支付，而非直接套用传统微信支付商户号。TencentCloudBase 官方参考资料已列出个人、企业与个体户的虚拟支付条件，以及 iOS 配置要求。个人主体不等于所有功能均能开放；地图解锁是否在允许服务类目和交易范围内，仍以实际账号和平台确认结果为准。

不要用普通商户支付资料推导个人虚拟支付权限。传统小程序支付的商户号、APIv3，与虚拟支付的 OfferID、AppKey、签名和回调是不同链路。

iOS 也不能依据旧资料直接判定不可付费。需分别检查 IAP 开通、客户端支持、商品发布、费率、退款与结算。此前 19.99 元与首批半价是商业假设；平台商品定价规则及各端可售价格需在支付接入前确认。活动费率不直接写成长期经营成本。

密钥通过服务端安全配置管理，不发到聊天、不写入前端或 Git。真实订单接入后验证签名、发货幂等、查单补偿和退款权益回收，前端成功回调不发放权益。

## 地图与外部数据

原生 map 组件与额外调用腾讯／高德位置服务 API 分开评估。地图组件展示、POI 检索、数据保存和商业使用不能统称“地图免费”；按实际服务账号、协议和使用方式确认费用与权利。

统一使用 GCJ-02 坐标，不混用 WGS84／百度坐标直接打点。首版固定上海区域，不自动请求用户定位；附近能力上线时再申请对应接口权限与隐私声明，拒绝定位也可选片区。

高德 POI 文档包含基础地点和部分商业字段，但不能据此假设有完整评价正文与闭店状态。小红书、大众点评公开内容可以提供发现线索；自动采集与转载的可行范围需要单独确认。首版不实现未授权的批量抓取。

## 部署与发布

小程序前端、云函数、数据库规则／索引、平台账号配置是四个部署部分。上传前端不代表云函数和数据库也已部署。

开发环境与生产环境分开，生产不放测试地点和演示购买。云端先发布兼容接口，再上传前端；发布前验证实际云环境，不能依靠关闭域名校验才运行。回滚前端时服务端保持接口兼容。

小程序备案、实际服务类目与资料、隐私保护指引、开发成员及体验成员配置都要在公众平台核验。发表评论和共创的类目条件单独检查，不假定个人工具类账号天然可以做开放社区。云开发不免除小程序备案。

通过开发者工具上传开发版，在公众平台设体验版，真机验收后提审，审核通过再正式发布。平台审核时间不包含在纯开发工时估算内。

正式运营前补充真实运营主体、用户联系与注销／删除途径、来源使用说明、买断权益边界。涉及投稿图片与评论时接入内容检测和举报机制；社区判断营业状态与内容审核是两个不同任务。
