# v0.3：云端共创与轻量审核

2026-10-16。黑白界面保留，费用与状态增加低饱和的绿、砂色、琥珀色；颜色都配文字，不承担唯一识别作用。

## 本版完成的工程

- 网站由静态预览升级为带 API 的服务。客户端仍使用 uni-app / Vue / TypeScript；Sites 的 Vinext 服务仅承载 API 与同一套 Web 产物，不另做一套 React 页面。
- 预览托管平台的 ChatGPT 身份登录、贡献署名。账号标识由服务端请求身份提供，客户端不能自行指定身份或审核角色。
- 云端地点投稿、草稿、修改与重新提交、门店基础去重、我的贡献、待审核 / 已收录 / 退回 / 隐藏状态。
- 审核在“我的”页面内完成；服务端 `REVIEWER_USER_IDS` 授权，默认无审核员。来源、收录门槛和处理依据都有展示与记录。
- 真实地点的收藏保存到云端并按账号隔离；虚构示例仍用本机存储，二者不混装成真实社区记录。
- 真实地点的空位反馈、体验投稿与审核、“有帮助”去重；不能给自己的公开体验自赞。空位由服务端记录时间，一小时过期。
- 闭店反馈按用户、规范化来源去重，使用近期证据。两位不同用户与不同来源达到条件后，标记“社区闭店”并默认隐藏，不宣称绝对事实；旧链接与收藏读取同步受限。审核恢复会清除旧的有效闭店反馈。
- 暂时停业、坐满、电脑规则和信息错误分别处理。纠错依据留在审核端，不公开举报者账号。
- 商家公开菜单链接、地址搜索入口、来源与资料日期。未获得允许公开的 Wi-Fi 信息时，不向真实地点展示演示密码。
- 六条公开资料线索可由审核员导入，均先进入待审核，不靠数据库迁移或请求读接口自动发布。

## 运行与技术目录

- `apps/client`：跨端主工程。
- `site-preview/app/api`、`site-preview/server`：Web API 与领域校验。
- `site-preview/db/schema.ts`、`site-preview/drizzle`：D1 数据结构与迁移。
- `site-preview/client`：发布仓库保留的同版本客户端源代码。
- `site-preview/public`：客户端构建产物。`npm run sync:web` 同步源码与产物。

本轮使用 Sites 托管的 D1 做轻量结构化存储，原先 PostgreSQL 是独立部署候选，没有开通或假装已经使用。服务 API 与客户端分开，未来可迁移后端，保留领域模型。

开发需 Node.js 22.13+。根目录 `npm test` 验证早期微信骨架、客户端空位逻辑与新的 HTTP API；发布仓库 `npm test` 单独验证当前 API。独立的早期微信云函数不服务本 Web。

## 当前实际边界

现在是私有内测服务，保留原访问范围。平台登录用于当前预览，面向国内普通用户的微信 / 邮箱登录尚未接入。微信小程序与 App 的实际身份传输、账号与发布仍需平台配置，不能仅靠编译产物声称可发布。

内置地图仍是清楚标注的布局示意，真实地点可按地址打开高德地图。该入口遵循[高德 URI 搜索文档](https://developer.amap.com/api/uri-api/guide/search/search)，不需要在客户端虚构坐标或 API Key。内置地图 SDK、真实定位与 POI 数据服务需要选定并配置服务账号。

没有接入 19.99 元买断支付、创建订单或授予假权益；支付账户、商品范围、公众发布条件与域名接入是后续接入事项。
